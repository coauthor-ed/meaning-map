## A Token Id Holds No Meaning

So what could hold meaning? Token ids cannot. In the token list from the second lesson, mother is token 1417 and father is token 1170, but bus is token 1413. Bus sits nearer to mother than father does, because ids only follow the order in which tokens were made.

**A token id is a token's number in the token list. It says nothing about what a word means.**

## Scores for Animals

A report card describes you with numbers, one mark for each subject, and we can describe animals the same way. Ask "How big is it?" and "How tame is it?", and score each animal from 0 to 10. Pick an animal and move its sliders until the scores seem fair.

**Animals with similar scores sit close together, so near can mean alike.**

<!-- STEP id="s3" -->
## Two Animals, One Spot

The dog and the goat now have the same two scores, because both are middle-sized and tame, so they share one spot. A third question, "Eats meat?", needs a direction of its own. So the flat graph tilts into a box, and the new score runs back into the picture. Pick the goat and slide its "Eats meat?" score down to 0, since goats eat only plants.

**A new question adds a new direction, and that direction can separate two animals.**

<!-- STEP id="s4" -->
## More Numbers Give More Room

Each new question adds one more direction, and so more room for different things to stay apart. A picture runs out of room after three directions, because a fourth question has no direction left to be drawn in. A word's list of numbers can be much longer: the real lists in this lesson have 300 numbers. Also, we chose these questions ourselves, so the scores hold only what we thought of.

**A picture can show at most three numbers, but a list can hold 300, if something chooses them.**
