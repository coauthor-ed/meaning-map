## Count the Difference

Run 1 is on the screen. Press **Run it again**, and the scene will compare the two pictures pixel by pixel, here in your browser. The third square marks in red every pixel that differs, and the count below it is the real count.

**Read the count before you go on.**

<!-- STEP id="s2" -->
## Zero Different Pixels

The count is 0 for this pair. That can feel wrong, because many apps give you a new picture every time you press the button. Those apps usually pick a new seed for you.

The seed sets the starting noise, which is the only random part of this run, and the later stages are fixed sums. No setting changes during a run, so the first run taught the model nothing.

**The same prompt, seed and strength should give the same picture.**

## Testing the Test

A rerun may still differ very slightly. A later rerun of ours looked the same but did not match in every number, and we have not found the cause. So this pair came out exactly the same, but small differences can appear on a later run or on another computer.

A count of 0 also means little if the counter cannot count. Tap **One word changed** and **New seed** to compare run 1 with other pictures.

**A zero only means something if the same test can also give a large number.**
