## A Sentence with a Mistake

"Calcutta is in France." You know this is false, because you have seen Calcutta on a map of India. A model has never seen a map. All it has is text, and the settings that the text built during training. So could it say this sentence as smoothly as a true one?

**A model knows the world only through the text in its pile.**

## What the Check Can See

Think back to the check in the Gym. We covered the last word of a line, and the pile marked the guess, so nothing in the check looks at the world. If a line is true, the check rewards a true word, and if it is false, the check works in the same way.

**The check compares a guess with the pile, and it has nothing else to compare with.**
