## Big Programs in Parts

A model alone does not run code. A program around it saves files and runs code. An app is written in parts: a plan first, then one part at a time.

**A plan in the window keeps each part small.**

<!-- STEP id="s2" -->
## Run, Read, Fix

When a part fails, the program puts the error into the context window. The model reads the error as text, and writes a new version. The coding lessons show this loop.

**Run the part, read the error, fix it, and run it again.**
