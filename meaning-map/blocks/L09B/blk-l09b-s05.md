## Two Attempts, One Checker

The toy tries the same sum twice. A checker is a program with an answer key. It marks only the final answer, not the steps.

Press Check answers.

**A checker marks only the final answer.**

<!-- STEP id="s2" -->
## Nudge the Working That Worked

Press Nudge. The steps of the right attempt get nudged up. Steps like them become more likely. Many newer models get training like this on maths and on code.

**A right final answer decides which working gets nudged up.**

<!-- STEP id="s3" -->
## Why Maths and Code Came First

This happens in training, and using a model changes no setting. Some companies have published how they do it. A model trained to write its working first is sometimes called a thinking model.

**Maths and code improved first, partly because a machine can mark them.**
