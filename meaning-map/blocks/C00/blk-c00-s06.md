## One Character Changed

Here is the same program with one change. Line 4 now says `m < top`, where the sign `<` means "less than". The writer wanted the top mark and pressed the wrong key.

Press Run line until the run ends, then read what it printed.

**One wrong character can change what a program does.**

## The Computer Does Not Guess

The printed number is lower than every mark. No mark is less than 0, so the `if` line answered no each time and `top` never changed. Python gave no warning, because each line was a line it could follow.

Use the buttons at the top to compare this run with the `m > top` run.

**A program does what it says, which may not be what you meant.**
