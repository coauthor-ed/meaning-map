## Telling a Computer What to Do

The last lesson asked how a model that picks one token at a time can write an exact program. What is a program?

Asha scored 78 in maths, and her teacher adds 5 grace marks to every paper. You can work out the new mark in your head, but a computer cannot guess what you want. You have to give it exact instructions, one after another.

Those instructions, written down, are called a program. The three lines beside this text are a real program in a language called Python.

**A program is a list of exact instructions, followed one line at a time.**

<!-- STEP id="s2" -->
## A Box with a Name

Press Run line to run line 1, which is `marks = 78`. The computer makes a box, writes the name `marks` on it, and puts 78 inside. Programmers call this box a variable, and you will see it appear under Boxes.

This scene plays a recorded run of real Python. We ran these exact lines and saved every step, so each number you see is true. You can go forward and back, but you cannot change the code.

**A variable is a named box that holds a value.**

<!-- STEP id="s3" -->
## This Is Not a Maths Equation

Line 2 looks impossible, because in maths `marks` cannot equal `marks + 5`. That reading is natural, but here `=` does not mean "is equal to". It means "work out the right side, then put the answer in the box on the left".

So Python takes the 78 out of the box, adds 5, and stores the result, which replaces the old value. Press Run line to see it happen.

**The `=` sign stores a value in a box.**

<!-- STEP id="s4" -->
## Asking to See the Answer

So far nothing has been printed, because storing a number does not show it to anyone. Line 3 is `print(marks)`. The word `print` means "show this on the screen", and the round brackets hold what to show.

Look carefully at what is inside the brackets before you press Run line, because the scene will ask you what appears.

**A computer shows you only what a print line tells it to show.**
