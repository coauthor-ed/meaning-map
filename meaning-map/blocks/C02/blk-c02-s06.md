## Step 1: Write a Plan

A big program is long, so it is written in parts. A part is a few lines of code with one job.

This toy first writes a plan, a short list of the parts. Press Write plan.

**A big program starts with a plan.**

<!-- STEP id="s2" -->
## The Plan Stays in the Window

The plan goes into the context window. The window holds all the text the model can read right now.

So the plan stays there. Every part can read it.

**A plan is text too, and it stays in the window.**

<!-- STEP id="s3" -->
## Step 2: Write the Parts

Now the toy writes the parts, one at a time. Press Next part three times.

Each part is a standard piece, seen many times, like adding up a list. So each part is easy to predict.

**Step 2 is one small part at a time.**

<!-- STEP id="s4" -->
## Where the Names Come From

The toy has one rule: it copies every name it needs from the window. A name, like `count`, holds a value.

Tap `count` in part 3. Gold rings show where it came from.

**Each part copies its names from the window.**
