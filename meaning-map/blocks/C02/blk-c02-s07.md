## Step 3: Run the Parts

The runner is the ordinary computer that runs code, as in Meena's first program. The model only writes the text.

We put one slip into part 2 on purpose. It says `mark`, not `marks`. Press Run.

**The runner runs the code, not the model.**

<!-- STEP id="s2" -->
## Step 4: Read the Error

The run stopped in part 2. An error is the runner's message about what went wrong. Here it says the name `mark` is not known.

Press Send error. The message goes into the window as text.

**The error becomes more text in the window.**

<!-- STEP id="s3" -->
## Step 5: Fix One Part

Press Fix part 2. The toy reads the error and the plan line for part 2. It rewrites only part 2.

Then the runner runs the program again. It prints 76.0, the average.

**With the plan in the window, one small fix is enough.**
