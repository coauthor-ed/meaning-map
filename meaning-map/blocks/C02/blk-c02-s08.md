## What If There Is No Plan?

Same toy, same rule, same slip, but this time there is no plan.

Part 3 must divide by how many marks there are. Which name will it use? Think first, then tap.

**This time, the window holds no plan.**

<!-- STEP id="s2" -->
## Run It with No Plan

Press Run. The slip in part 2 is fixed. Then part 3 fails, because no part made `count`.

Rewriting part 3 gives the same line. The missing line belongs in part 1.

**The part that fails is not always the part that is wrong.**

<!-- STEP id="s3" -->
## Plan On and Plan Off

With the plan, part 1 made `count`, and the program ran. Without it, part 1 never did.

Real models do far more work per token than this toy. Still, they write one token at a time.

**A plan in the window helps the parts fit together.**
