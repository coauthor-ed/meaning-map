## Twelve Words

Someone typed these twelve words into a computer program and pressed a button. Read them slowly, and try to imagine what could come out. The program was given no drawing and no photo, so everything you are about to see had to start from these words.

**Twelve words went in, and no picture went in with them.**

<!-- STEP id="s2" -->
## The Picture

This picture came out, and no person drew it. A program called Stable Diffusion made it, and the tag on it says so. The program also received one number, called a seed, which makes each run start differently, and we kept the best picture from 12 seeds. Look at how many things the words asked for: a dragon, its colour, the ice cream, and a sunny park.

**A machine turned twelve words into this picture.**

<!-- STEP id="s3" -->
## How?

This should seem strange, because a computer only handles numbers. It has never watched a dragon fly or tasted ice cream, and it has no eyes. Yet it took a line of English and gave back a picture that fits. This course explains how, one step at a time, with things you can try yourself.

**A computer only handles numbers, so how did it do this?**
