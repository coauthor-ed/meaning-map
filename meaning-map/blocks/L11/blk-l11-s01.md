## A Picture Is a Grid

A sentence became a short list of token ids, but a picture is much bigger than that. This cricket ball is a tiny picture, only 64 pixels wide and 64 pixels high. A pixel is one small square of colour, and the lines on the picture mark every one of them.

**A picture is a grid of small squares of colour.**

<!-- STEP id="s2" -->
## Three Numbers in Every Pixel

Tap any pixel and read what is stored there. A screen makes each colour by mixing red, green and blue light, so a pixel holds three numbers, each from 0 to 255. The computer stores no ball anywhere, because a picture in memory is only these numbers.

**A pixel is three numbers, each from 0 to 255.**

<!-- STEP id="s3" -->
## The Full Count

There are 64 rows of 64 pixels, which gives 4,096 pixels, and each pixel holds three numbers. So this small picture is a list of 12,288 numbers.

**A tiny picture of one ball is 12,288 numbers.**

Most of those numbers only repeat the plain background, so does the picture really need all of them?
