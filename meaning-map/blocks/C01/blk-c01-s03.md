## Tap the Prompt

Tap `each m among` and read what the chart shows. Then tap `for m in`, a prompt from the pile, and compare the two.

The tool does not understand any of these words, because all it does is match the tokens and count what follows them.

**The bars come only from the lines in the pile.**

## Adding Lines

Press the button to add five lines of Pipal to the pile, then look at the chart for `each m among`. The language is still made up, but now there is something to count.

Press the button again to take the lines out, and watch the chart change back.

**Examples are what the bars are built from.**

## Where the Counter Stops

You might now think a real model would have nothing to write for Pipal too. That does not follow, because a real model is not a table of counts. It would still score every token and still write something.

We have not tested what a real model does with Pipal, so we make no claim about how good that writing would be.

**Our test shows how counting works, and it does not show what a real model would do.**

## A Good Guess Is Still a Guess

Code online often sits beside its error messages and the fixes people found, so a pile may hold those too. That may help with common mistakes, but it is not a check, because code is normally not run while a model trains.

A high score means a token is likely. It does not mean the program will work.
