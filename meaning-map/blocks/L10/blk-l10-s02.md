## What the Words Have Shown

You can now follow a model from text to answer. Text becomes tokens, each token finds its embedding, attention makes working copies, and the model scores every token and picks one. Training built all of this from a pile, which is why an answer can be smooth and still be false.

For harder problems, written working stays in the window and is read again. Many newer models also practise against a checker.

**A model calculates the next token from numbers that a pile shaped.**

## A Much Larger Problem

All of that was about text, and a short sentence becomes only a short list of token ids. The dragon from the first lesson is still not explained, and a picture on your phone holds far more numbers than any sentence. The same ideas might still help, but that is not yet clear.

**A picture has far more numbers than a sentence. Could the same ideas work?**
