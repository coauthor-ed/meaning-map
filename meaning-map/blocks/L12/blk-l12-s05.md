## Open a Random Latent Code

All the latent codes that could exist, taken together, are called latent space. With the ball, any random three numbers opened into a ball. So try the same test here. Press Open to give the real decoder a latent code of 16,384 random numbers.

**Could a random latent code open into a picture, as it did with the ball?**

<!-- STEP id="s2" -->
## What the Decoder Made

You may have expected a strange creature, or perhaps a blurred scene. Instead the decoder made coloured speckle that shows nothing at all. This is real output, not a drawing, so press Another latent code to see two more random latent codes. The small curved patches are the decoder's own marks, which is why this looks different from random pixels.

**This is real decoder output, and it shows nothing.**

<!-- STEP id="s3" -->
## Why the Ball Was Different

The ball's three numbers were all real choices, so every list opened into a ball. A real latent code has room for far more than pictures use. So a random list almost never lands on the small part of latent space that opens into a picture.

**Random latent codes open into speckle, not pictures.**
